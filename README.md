# Yunik's Portfolio

Modern, interactive portfolio website for Yunik — Developer, Designer, and Creator based in Nepal.

## Features

- 🎨 Clean, developer-crafted UI with smooth animations
- 🌓 Light/Dark theme toggle with system preference detection
- ✨ Real-time mouse-following spotlight effect
- 🎮 Playable interactive mini-projects (Calculator, Number Guesser, Click Speed Test, etc.)
- 🎭 Floating particle canvas with physics-based mouse interaction
- 📱 Fully responsive design
- 🎯 3D tactile circular contact buttons

## Run Locally

Python is enough (Node is not required):

```bash
cd portfolio
python -m http.server 8080
```

Open http://127.0.0.1:8080
